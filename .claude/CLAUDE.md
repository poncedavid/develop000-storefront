# Instrucciones — Develop000-Storefront

Tienda pública del e-commerce (Next.js 16 + TypeScript + Zustand).

---

## 🎯 Prioridades

1. SEO perfecto — JSON-LD, OG tags, sitemap
2. Performance — ISR, image optimization
3. UX de compra fluida

---

## ⚙️ Stack

- Next.js 16 App Router
- TypeScript strict
- shadcn/ui + Tailwind CSS v4
- Zustand (estado del carrito)
- GraphQL (queries a AppSync)

---

## 🚫 Antes de Codear

1. Lee `.claude/steering/00-proyecto.md`
2. Entiendes Next.js App Router
3. Sabes usar Zustand para estado
4. Conoces SSR/SSG/ISR

---

## ✅ Convenciones

- TypeScript strict (NUNCA `any`)
- Metadata para SEO en cada página
- Zustand + localStorage para carrito
- GraphQL queries tipadas
- shadcn/ui para componentes

---

## 🚀 Comandos

```bash
npm run dev       # Servidor local
npm run build     # Build
npm run test      # Tests
```
